# 搜索结果页面优化计划

## 页面结构分析

### 当前页面组成
1. **nav-bar**: 导航栏（返回按钮 + 标题 + 右侧空白）
2. **sx**: 筛选区域（筛选按钮）
3. **content**: 商品列表
4. **filter-modal**: 高级筛选弹窗

### 用户需求
1. navbar下方增加高级分割线
2. 筛选右侧增加关键词搜索输入框
3. 下方增加分割线分隔区域
4. 整体样式优化：高端大气上档次

---

## 优化方案

### 1. 导航栏优化
- navbar下方添加渐变分割线（使用伪元素）
- 保留现有结构，调整间距

### 2. 筛选搜索栏优化
- 左侧：筛选按钮（带图标）
- 中间：关键词搜索输入框
- 右侧：空白区域保持对称
- 添加底部分割线

### 3. 商品卡片优化
- 卡片添加精致阴影
- 悬停/点击动效
- 图片添加渐变遮罩
- 价格使用金色强调

### 4. 整体配色方案（高端奢华风）
- 主色：深灰 #1a1a1a
- 强调色：香槟金 #D4AF37
- 背景色：米白 #FAFAFA
- 分割线：渐变金色
